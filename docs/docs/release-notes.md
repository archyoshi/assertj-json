# Release Notes

Stay up to date with the latest changes and improvements to AssertJ-JSON.

## v0.1.2

Initial beta release available via JitPack.

*   Introduced fluent AssertJ style assertions for JSON structure and values.
*   Seamless integration with Jackson `JsonNode`.
*   Support for parsing and asserting on JSON strings, `Path`, and `File` inputs.
*   Added core validation methods: `hasField`, `hasValueForField`, `hasSameContentAs`, `hasSameFieldsAs`, and `partiallyContains`.
*   Added array assertions via `assertThatArray`.
