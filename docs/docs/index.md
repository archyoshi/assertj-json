# AssertJ-JSON

AssertJ-JSON is an extension for the [AssertJ](https://assertj.github.io/doc/) library that provides fluent assertions for JSON strings. It allows you to easily verify the structure, values, and types of JSON nodes within your tests, making JSON testing intuitive and readable.

## Why AssertJ-JSON?

When testing REST APIs or systems that process JSON, validating the output can become cumbersome. Standard assertions require parsing the JSON manually and writing verbose assertions. AssertJ-JSON simplifies this by integrating directly with AssertJ's fluent API.

## Features

- **Fluent API:** Seamless integration with AssertJ's `assertThat`.
- **Type Checking:** Verify if a node is an object, array, string, number, boolean, or null.
- **Value Assertions:** Check specific values within JSON nodes.
- **Path Extraction:** Extract nodes using JSON path-like syntax.
- **Structure Validation:** Ensure JSON objects contain expected keys or arrays have expected sizes.
