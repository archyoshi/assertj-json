# Mailing List

If you have questions, suggestions, or want to discuss the library, the best place to do so is through GitHub Discussions or Issues.

Since AssertJ-JSON is a community extension, it does not currently have its own dedicated mailing list.

*   **GitHub Discussions:** [Join the conversation](https://github.com/archyoshi/assertj-json/discussions)
